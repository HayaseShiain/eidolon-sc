# 08: 拍板：成就的奖励

Type: grilling
Status: open
Blocked by: 05

## Question

- 每个阶段给什么：抽奖次数、礼物、重置卡，还是什么都不给、只展示（调研：外在奖励会挤掉乐趣，Hecker 建议成就奖励出乎意料、传达信息）。地图 Notes 已定只给背包里的东西，不直接加好感度。
- 给多少：各阶段一样，还是越往后越多；按角色的成就有 28 套，总量要算一遍。
- 「集齐一类」的额外奖励要不要（例如某位角色的成就全部解锁）。
- 到账：解锁时自动到账（同每日任务），还是要用户去领。
- 上线补算一次给出的量：老用户可能一下解锁十几个阶段，要不要封顶或折算。
- 抽奖类成就拿抽奖换抽奖：「抽过几次奖」给抽奖次数会不会自己喂自己。
