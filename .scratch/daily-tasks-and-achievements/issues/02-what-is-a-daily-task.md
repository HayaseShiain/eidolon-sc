# 02: 拍板：每日任务是什么

Type: grilling
Status: open
Blocked by: 01

## Question

- **叫什么**：「每日任务」是暂定名。要不要借世界观写成某个角色发的委托（例如事务员七草はづき，重置卡插画画的就是她），还是就叫系统的任务。定了写进 `GLOSSARY.md`。
- **每天几项**，固定的还是从池子里抽；北京时间 0 点换（和抽奖一样）。没做完的过了一天是作废还是保留。
- **今日偶像**：要不要每天指定一位偶像，任务围绕她；每个用户各抽各的还是全站同一位；冷却中的偶像排不排除（隐藏只存在浏览器里，服务器排除不了）；一位偶像都没聊过的新用户怎么办。
- **什么算完成**：只用服务器能核实的事。候选有：和某位偶像有一个回合、接通一次通话、送一次礼、和几位不同的偶像说话。
  - 通话任务会让人为了做任务打电话，花的是部署者的语音识别和语音合成，要不要放进来。
  - 自带密钥的回合算不算（`messages` 不区分，见地图 Notes）。
  - 冷却中、被她结束的对话里的事算不算。
  - 不做「给某位偶像加几次好感」这类任务（会变成讨好判断模型，没有判断模型时也做不了）：确认一下。
- **完成怎么记**：动作发生时另记一条，还是读取时去查今天的回合、通话、送礼（删掉历史对话会让已完成的变回没完成）。
- **领奖**：做完自动到账，还是要用户来点一下领取。
