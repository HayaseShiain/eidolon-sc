# 03: 调研：原版的画面、界面流程和素材清单

Type: research
Status: open
Blocked by: none

## Question

给票 08 的原型备料：原版的酒吧画面由哪些素材拼成、怎么动。要查：

- **画面布局**：640×360 的画面上左半边客人、右半边调酒台和配方书、下方文本框（`backgrounds/00_bar_frame.png`、`sprites/002_barground.png` 这些）各自的位置和尺寸；文本框里名字、台词的排法，一次显示几行。
- **调酒台的流程**：点材料加份数、加冰、陈化、开始摇（摇的时长决定 mix 还是 blend）、上酒、重来，每一步用哪张图（`*_hover`、`*_off` 变体，`shaker_*`、`shakerpulse_*`、`agesprite`、`icesprite`……）、哪个音效（`addingredient`、`iceadd`、`ageadd`、`mixdone`、`glassserve`……）。
- **文本**：打字速度、每个字一声还是每几个字一声、用 `bleep_high`、`bleep_low` 还是别的、不同角色的音效是否不同、点一下跳到整句。
- **素材清单**：做酒吧这一版要用到的图和音频，列文件名（提取目录里的）、尺寸、用途；顺带列出配乐里哪些适合当酒吧的背景音乐。
- **手机**：已定只支持横屏，竖屏只显示「请横过来」的提醒，不做竖屏布局。要查：网页能不能锁横屏（Screen Orientation API 在安卓 Chrome、iOS Safari 上的支持和前提，比如要不要先进全屏）；怎么检测竖屏、显示提醒；横屏手机去掉地址栏、刘海和安全区后的可视高度，640×360 能整数倍放大到几倍；同类网页像素游戏的横屏提醒一两个例子。

产出是一份带截图或拼图的调研笔记，结论在前。
