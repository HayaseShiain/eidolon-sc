# 07: 拍板：上了酒之后怎么判、戏怎么走、好感度加多少

Type: grilling
Status: open
Blocked by: 01, 02, 05

## Question

制作人上了一杯饮品，服务器怎么判、她怎么反应。要定：

- **判定的档位**：上对、上得更好、上错（差得不多 / 完全不对 / 调失败了的饮品），各自她的反应和后面的戏怎么变（照票 02 原版的做法）。上错了她会不会再给一次机会。
- **酒精**：Karmotrine 的量（含大杯）怎么累积成「醉」，醉了几档、各自什么样（定图时的护栏：只是话多、犯困、情绪起伏、说心里话）；故意把她灌醉算上对还是上错，原版有没有「灌醉才能听到的话」那种隐藏分支，我们要不要。
- **好感度加多少**：定图时定了上对多加、上错少加、都不降，只有当天第一次玩完的光顾算。按「好感度放慢」那把尺子（`.scratch/play-and-schedule/issues/11-*`）和礼物、工作比，这次光顾整体加多少，按杯算还是按整次算。
- **抽奖次数**：当天第一次玩完给几次，算不算进每天发的上限（成就给的不算上限，酒吧的呢）。
- **什么算「玩完」**：最后一杯上完、她离开那一刻；中途走了不算。
- **选项**：偶尔出现的两三个选项（制作人的台词）放在哪里、选了怎么影响戏，影不影响好感度。
- 调错的饮品：原版对不上配方的是「故障瓶」，上不了、只能重做（票 01）；照搬，还是允许上、算上错。
- 原版吧台上**没有选项**、上错几乎不让重做、只有「连着乱上最省事的」会被赶回家（票 02）。定图时定的「偶尔给两三个选项」要不要留，也在这里定。
